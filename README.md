# Amrit Sovereign - Premium Dairy E-commerce

A premium Next.js e-commerce frontend for Amrit Sovereign dairy products.

## 🚀 Live Demo

Visit: [Your Vercel URL]

## ✨ Features

- **Premium UI/UX** - Glassmorphism, animations, gold accents
- **21 Products** - Dairy, Oils, Superfoods categories
- **Headless WordPress Ready** - WooCommerce integration
- **On-demand Revalidation** - Automatic cache purge
- **Preview Mode** - WordPress draft previews

## 🛠️ Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 🐳 Development with Containers

For improved performance and consistent development environment, you can use the provided dev container configuration:

1. Install Docker Desktop
2. Install the "Remote - Containers" extension in your IDE
3. Reopen this project in a container: `Ctrl+Shift+P` → "Dev Containers: Reopen in Container"

This approach isolates the development environment and can help reduce resource consumption on your host machine.

## 🔗 WordPress Integration

1. Install Antigravity Headless Bridge plugin
2. Configure frontend URL in plugin settings
3. Add WooCommerce API keys to `.env.local`
